# Avalon Helper

线下阿瓦隆辅助网页工具。

这是一个给线下桌游局使用的辅助网站，不是完整线上桌游。玩家仍然在线下面对面发言、博弈，网页负责管理房间、发身份、展示私有视野、推进提名/投票/任务/刺杀流程，并记录整局结果。

## 项目特性

- Next.js App Router + TypeScript
- Prisma + PostgreSQL
- Socket.IO 实时同步
- 服务端状态机控制流程
- 后端为唯一真相来源
- 私有身份与视野由服务端生成
- 支持断线重连
- 支持房主强制推进
- 支持有限回退
- 支持游戏结束后进入“新一局准备”

## 已实现流程

- 创建房间 / 加入房间
- 房主锁房 / 解锁 / 移除玩家
- 5 至 10 人标准配置发牌
- 身份查看与确认
- 队长轮转、队伍提名、全员投票
- 连续 5 次提名否决则坏人直接获胜
- 任务成员提交成功 / 失败
- 第 4 轮双失败规则
- 3 次任务成功后刺客刺杀
- 刺客可中途发起翻牌刺杀
- 对局公开记录与结果页

## 标准自动配角

- 5人：梅林、派西维尔、忠臣、莫甘娜、刺客
- 6人：梅林、派西维尔、忠臣 x2、莫甘娜、刺客
- 7人：梅林、派西维尔、忠臣 x2、莫甘娜、刺客、奥伯伦
- 8人：梅林、派西维尔、忠臣 x3、莫甘娜、刺客、普通爪牙
- 9人：梅林、派西维尔、忠臣 x4、莫甘娜、刺客、莫德雷德
- 10人：梅林、派西维尔、忠臣 x4、莫甘娜、刺客、奥伯伦、莫德雷德

## 主要页面

- `/` 首页
- `/create` 创建房间
- `/join` 加入房间
- `/room/[code]` 房间大厅
- `/game/[code]` 游戏主页面
- `/result/[code]` 结果页

## 环境要求

- Node.js 18 或更高
- PostgreSQL 14 或更高

## 环境变量

先复制环境变量模板：

```bash
cp .env.example .env
```

默认示例：

```bash
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/avalon_helper?schema=public"
PORT=3000
```

可选：

- `PORT`：本地开发端口
- `HOSTNAME`：局域网调试时可设为 `0.0.0.0`

## 安装

```bash
npm install
npx prisma generate
```

## 数据库初始化

先创建数据库 `avalon_helper`，再执行迁移：

```bash
npx prisma migrate dev
```

如果是第一次拉起项目，Prisma 会自动应用已有 migrations。

## 当前交互规则说明

- 游戏开始后，其他新玩家不能中途加入当前局。
- 游戏结束后，房主点击“新一局准备”会回到大厅。
- 回到大厅后可以加人、减人、锁房，再重新开始。
- 任务结果会自动进入下一轮，不需要房主手动点下一轮。
- 刺客翻牌刺杀阶段会公开除奥伯伦外的坏人及其具体身份。
